# odoo-query-ai

AI-powered natural language query assistant for Odoo 13–18.
Ask business questions in plain English and get real-time ERP data.

## Features
- Natural language → Odoo ORM query
- Supports Sales, Accounting, Inventory
- Works on Odoo 13 through 18
- Powered by Claude (Anthropic)

## Setup
1. Copy `odoo_ai_query/` into your Odoo addons folder
2. Install the module from Apps
3. Add your Anthropic API key in Settings → AI Query
